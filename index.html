Ecossistema Open Source Django

Pacotes, Temas Admin & Integrações Django

Uma suíte completa de repositórios open source desenvolvida para acelerar a criação de aplicações web em Django: temas administrativos, autenticação SSO (Gov.br, SUAP, Sabiá), motor de regras e integrações.

Temas de Administração

🎨 Temas para Django Admin

Customizações visuais e estruturais para a interface administrativa nativa do Django. Nossos temas transformam a experiência de uso adicionando navegação responsiva moderna, dashboards, buscas globais e conformidade com padrões oficiais de design como o DSGovBR.

🎨

django-admintheme-adminlte3

Tema elegante e completo baseado no consagrado AdminLTE 3 adaptado nativamente para o Django Admin com menu expansível, barra de busca global e componentes visuais modernos.

Django AdminLTE 3 Admin Theme
GitHub Documentação
🏛️

django-admintheme-dsgovbr

Integração oficial e acessível do Design System do Governo Federal Brasileiro (DSGovBR / Padrão Digital de Governo) com a interface do Django Admin e formulários.

Django DSGovBR Governo Federal Acessibilidade
GitHub Documentação
🧪

django-admintheme-sandbox

Aplicação Sandbox / Playground para testar, visualizar e demonstrar os temas de administração Django (AdminLTE3 e DSGovBR) pré-configurada com dados de exemplo.

Django Sandbox Playground Demo
GitHub
Autenticação & Identidade

🔐 Autenticação & Single Sign-On (SSO)

Módulos de autenticação e identificação de usuários integrados a provedores e plataformas governamentais e educacionais. Simplificam a implementação de login único (OAuth2 / OpenID Connect) com suporte flexível a Gov.br, SUAP, Sabiá e Moodle.

🔐

django-auth-govbr

Pacote de autenticação Django para integração SSO via Gov.br (OAuth2 / OpenID Connect) com mapeamento customizável de atributos de usuário, tokens JWT e callbacks.

Django Gov.br OAuth2 OpenID Connect
GitHub Documentação
🐦

django-auth-sabia

Módulo de integração de autenticação Single Sign-On (SSO) para aplicações Django com a plataforma e ecossistema de serviços Sabiá.

Django Sabiá SSO Auth
GitHub Documentação
🏫

django-auth-suap

Integração de autenticação SSO via OAuth2 com o SUAP (Sistema Unificado de Administração Pública dos Institutos Federais) para projetos Django.

Django SUAP OAuth2 IFRN
GitHub Documentação
Regras & Integração

⚙️ Core & Motores de Regras

Bibliotecas essenciais para regras de negócio declarativas e integração de dados. Permitem definir motores de regras flexíveis (elegibilidade, permissões, coortes e validações dinâmicas) e conectar o ORM do Django à infraestrutura do Moodle.

⚙️

django-rule-engine

Motor declarativo de regras de negócio para Django, ideal para avaliação flexível de elegibilidade, descontos, coortes, regras de acesso e validações dinâmicas.

Django Rule Engine Python Core
GitHub Documentação
📦

django-wrapper-moodle

Wrapper ORM Django para conexão, leitura e integração direta com tabelas e estruturas do banco de dados Moodle em aplicações Python.

Django Moodle ORM Wrapper
GitHub Documentação
Aplicações Práticas

🚀 Aplicações Web

Sistemas web completos prontos para produção construídos com a pilha tecnológica do ecossistema. Demonstram na prática o uso integrado de temas, autenticação SSO via Gov.br e SUAP, tarefas assíncronas com Celery e PostgreSQL.

🚀

django-project-processo-seletivo

Sistema web para gestão de processos seletivos, inscrições online, avaliação de recursos e publicação de resultados, com suporte a autenticação Gov.br e integração SUAP.

Django Celery Docker PostgreSQL REST API
