Início Rápido

Instale e ative um dos temas em seu projeto Django em menos de 2 minutos

# 1. Instale o tema desejado via pip
pip install django-admintheme-adminlte3
# ou
pip install django-dsgovbr

# 2. Adicione ao INSTALLED_APPS do settings.py (ANTES do 'django.contrib.admin')
INSTALLED_APPS = [
    'adminlte3',          # ou 'dsgovbr'
    'django.contrib.admin',
    'django.contrib.auth',
    ...
]

# 3. Colete os arquivos estáticos e rode a aplicação
python manage.py collectstatic --noinput
python manage.py runserver

Desenvolvimento Local com o Workspace

Como contribuir com os projetos da organização utilizando a CLI datw

# 1. Clone o repositório workspace privado
git clone git@github.com:django-adminthemes/workspace.git ~/projetos/PESSOAL/django-adminthemes/workspace
cd ~/projetos/PESSOAL/django-adminthemes/workspace

# 2. Execute o setup automatizado (clona todos os repositórios e ajusta o ambiente)
./datw setup

# 3. Inicie os containers Docker de desenvolvimento
./datw launch

# 4. Execute comandos do Django de forma unificada
./datw manage adminlte3 migrate
./datw manage adminlte3 createsuperuser
